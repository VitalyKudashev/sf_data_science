### Описание проекта
**Цель проекта:** разработать программу, которая угадывает загаданное компьютером число за минимальное количество попыток.

[⬆️ К оглавлению](#оглавление)

### Решаемая задача
Необходимо создать алгоритм, который будет эффективно угадывать число в заданном диапазоне.

**Условия задачи:**
* Компьютер загадывает целое число от 0 до 100
* Программа должна определить это число
* Доступна информация о том, больше или меньше загаданное число

**Метрика оценки:** среднее количество попыток при 1000 повторений

**Ключевые навыки:**
* Написание эффективного кода на Python
* Разработка алгоритмов

[⬆️ К оглавлению](#оглавление)

### Этапы работы над проектом

**Основной алгоритм:**
```python
def game_core_v3(number: int = 1) -> int:
    """
    Функция для угадывания числа методом бинарного поиска.
    Гарантированно находит число за 7 попыток или меньше (для диапазона 1-100).
    
    Args:
        number (int, optional): Загаданное число в диапазоне 1-100. Defaults to 1.

    Returns:
        int: Число попыток
    """
    count = 0
    low = 1
    high = 100
    
    while low <= high:
        count += 1
        mid = (low + high) // 2
        
        if mid == number:
            return count
        elif mid < number:
            low = mid + 1
        else:
            high = mid - 1
    
    return count  # Этот return фактически никогда не выполнится для корректного ввода
```

**Особенности реализации:**
* Используется метод бинарного поиска
* Максимальное количество попыток — 7
* Алгоритм гарантированно эффективен для диапазона 1-100

def score_game(random_predict):
    count_ls = []
    np.random.seed(1)
    random_array = np.random.randint(1, 101, size=(1000))
    for number in random_array:
        count_ls.append(random_predict(number))
    score = int(np.mean(count_ls))
    print(f"Ваш алгоритм угадывает число в среднем за {score} попыток")
